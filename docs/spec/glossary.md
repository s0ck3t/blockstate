# Glossary — Blockstate (`blockstate`)

All downstream specifications, user stories, tests, and codebase implementations must use these canonical terms verbatim. Synonyms are prohibited.

## Core Statechart & Execution Terms

- **Statechart:** A formal, deterministic finite-state machine supporting hierarchical states, entry/exit actions, declarative transitions, and stage guards, managed strictly by the Python runtime (`blockstate.core.engine.StatechartEngine`).
- **Declarative Control Grammar (DCG):** The static Python decorator and type-annotation subset (`@Stage`, `@Transition`, `@Guard`) that constrains workflow routing to compile-time resolvable state definitions, circumventing Rice's Theorem on Turing-complete Python reflection (`getattr(self, dynamic_state)()`) and enforcing `[Blockstate E014]` when dynamic transition destinations are detected.
- **Stage:** An isolated conversational and operational state declared via `@Stage`. Defines permitted tools, target slot-collection models (`collect`), permitted digressions (`allow_digressions`), optional turn allowances (`max_turns`), and deterministic fallback targets (`on_breach`, `on_max_turns_exceeded`, `on_refusal`, `on_security_violation`).
- **Stage Guard:** A deterministic Python condition declared with `@Guard` and `@Transition` / PEP 695 return-type union (`Transition["target_a" | "target_b"]` or `Transition[None]`) that governs whether a transition to a target Stage is permitted.
- **Tool Gating:** The physical scoping of tools such that unpermitted functions do not exist in the model's outbound schema payload or the runtime dispatch table for that turn (`blockstate.core.gatekeeper.ToolGatekeeper`).
- **Dispatch Table:** The ephemeral, memory-isolated lookup mapping (`types.MappingProxyType[str, Callable]`) binding whitelisted tool names to callable function pointers for the active turn.
- **Dominator Tree:** A tree representing dominator relationships in the statechart Control Flow Graph (CFG), where stage $D$ dominates stage $N$ ($D \text{ dom } N$) if every execution path from the root entry stage to $N$ must pass through $D$.
- **Static Graph Compiler:** The offline CLI inspection engine (`blockstate check` and `blockstate verify` in `blockstate.compiler`) that parses Python ASTs over the Declarative Control Grammar (`@Stage`, `@Transition`, `@Guard`) to extract statechart topology, reject dynamic transition destinations (`[Blockstate E014]`), and verify safety invariants without executing user or LLM code.

## Memory, Slot Hydration, Digression & Storage Terms

- **TaskFrame:** A discrete unit of execution context containing the active stage identifier, partially hydrated slots, locked leaf paths (`locked_slots`), turn counts, and frame-local metadata.
- **TaskStack:** A bounded Last-In, First-Out (LIFO) call stack (`max_stack_depth=6`) of `TaskFrame` objects managing multi-turn conversational detours and pushdown automata execution.
- **PartialSlotModel:** A dynamic recursive metaclass wrapper (`PartialSlotMetaclass`, `max_nesting_depth=8`) derived from a target Pydantic `BaseModel` that defaults required fields to the `UNSET` sentinel during intermediate multi-turn collection while enforcing `@field_validator(mode="after")` validators on supplied leaf values.
- **$\Delta$-Hydration:** The automated calculation of remaining uncollected leaf paths per turn: $\Delta = \text{RequiredLeafPaths} \setminus \text{HydratedLeafPaths}$.
- **Global SessionState:** Cross-cutting, verified facts (e.g. `user_id`, `auth_level`, `is_suspicious`) persisted atomically across the entire session inside `SessionCheckpoint`, isolated from ephemeral `TaskFrame` state.
- **ReadOnlySessionView:** A deep-frozen read-only projection of `SessionCheckpoint` passed to stage guards, classifiers, and tool handlers so that only `StatechartEngine.commit_turn()` can mutate session state.
- **SessionCheckpoint:** The atomic persistence unit stored via `StorageBackend` / `StateStore`, containing `schema_version`, monotonic `revision_id` (optimistic Compare-And-Swap), `Global SessionState`, `TaskStack`, `last_ledger_hash`, `pending_ledger_outbox`, and the AES-256-GCM AAD-encrypted `vault_map`.
- **StorageBackend SPI:** The formal asynchronous storage Service Provider Interface (`src/blockstate/ports/storage.py`) governing distributed session leasing, optimistic Compare-And-Swap (`revision_id`), and `SchemaUpcaster` migrations across the three canonical v1 backends—**In-Memory** (hermetic unit testing and CI/CD), **Local SQLite with WAL mode** (`PRAGMA journal_mode=WAL` via `aiosqlite` at `.blockstate/state.db`), and **PostgreSQL via async SQLAlchemy** (`SQLAlchemy[asyncio]` + `asyncpg`)—while providing the extension boundary for v1.2+ backends (Redis, Microsoft SQL Server, AWS DynamoDB).

## Turn Pipeline, Security & Handoff Terms

- **Two-Pass Turn Loop:** The decoupled three-phase turn execution pipeline over a canonical `TurnEnvelope`: Pass 1 (fast intent classification and candidate slot extraction via System-1 ONNX classifiers or SLMs in `< 100ms`), Core Resolution (`StatechartEngine.step` in `<= 5ms`: Step 2a Hydrate $\Delta$, Step 2b Scoped Stage Tool Execution, Step 2c Pure Stage Guard Evaluation), and Pass 2 (`ResponseRenderer.render` via deterministic templates, `ChoicePayload`, or scoped LLM rendering).
- **ChoicePayload:** A structured multiple-choice response model rendered deterministically in Pass 2 (`< 120ms` end-to-end turn SLA) for client-selectable options without invoking an LLM.
- **TurnLedger:** An append-only, tamper-evident audit stream (`TurnLedgerRecord`) recording state transitions, RFC 8785 JCS canonicalised prompt/input/output hashes, `exposed_tools`, guard outcomes, and chained SHA-256 hashes (`prev_record_hash`) per conversational turn.
- **PIIVault:** The post-lease ingress/egress sanitisation boundary (`PIIStripper` protocol in `blockstate.security.vault`) that maps detected PII/PHI spans to deterministic HMAC-SHA256 session tokens (`<VAULT:CATEGORY_NN>`) before Pass 1 and encrypts `vault_map` with AES-256-GCM bound to `AAD = "<session_id>:<schema_version>:<revision_id>"`.
- **`Vaulted[T]` & `Detokenise[T]`:** Type annotations governing `PIIVault` boundaries: `Vaulted[T]` performs isolated zero-persistence in-memory detokenisation strictly during Pydantic `@field_validator` checks before re-binding the `<VAULT:CATEGORY_NN>` token; `Detokenise[T]` authorises `ToolGatekeeper.invoke()` to pass raw detokenised values into an isolated tool handler.
- **Orchestrator Handoff Protocol & Enclave Adapter (`as_tool()`):** The transactional compliance execution enclave boundary (`from blockstate.adapters.langchain import as_tool`, `Agent.as_tool()`, and `Agent.run_as_subflow()`) allowing external general-purpose LLM orchestrators (LangGraph, Microsoft Semantic Kernel, AutoGen, AWS Bedrock) to mount a verified Blockstate statechart as a single validated tool—avoiding the "Enterprise Island Trap"—and receive a discriminated union (`BlockstateTurnYield | BlockstateTurnAborted | BlockstateTurnComplete[T]`).
