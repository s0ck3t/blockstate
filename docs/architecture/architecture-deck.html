Two-Pass Turn Loop, TaskStack Digressions & as_tool() Enclave

Each utterance traverses a three-stage pipeline: fast non-autoregressive extraction (Pass 1), synchronous Python statechart resolution (≤ 5ms), and scoped rendering (Pass 2)—exposed to LangGraph, Semantic Kernel, and AutoGen as a single transactional compliance enclave tool.

1. Pass 1: Fast Extraction< 100ms Budget
  • System-1 ONNX / ModernBERT: Local CPU/GPU inference offloaded via asyncio.to_thread achieves p95 ≤ 50ms (with tokenizers).
  • Scoped Δ Target: Pass 1 receives only the unhydrated leaf paths (Δ = Required \ Hydrated) of the active PartialSlotModel.
  • Refusal Short-Circuit (FR-3): Upstream safety refusals route immediately to on_refusal without burning ordinary retries.
2. Core Engine & TaskStack≤ 5ms Pure Python
  • Recursive PartialSlotModel (AD-5): Nested Pydantic models validate supplied fields per turn and lock valid leaf paths in TaskFrame.locked_slots.
  • Pushdown Digressions (FR-8/9): Off-topic allowed intents push a child TaskFrame (max depth 6) with read-only parent slot isolation (allow_slot_overrides=False).
  • Fail-Safe Counter-Metric (SM-C1): Unmapped intents trigger deterministic clarification or escalation—never probabilistic guessing.
3. Outer Enclave EntrypointAD-10 · as_tool()
  • Defeating the Enterprise Island Trap: Keep existing LangGraph / Semantic Kernel / AutoGen conversational routers intact.
  • Transactional Enclave Tool: Bind any verified Blockstate statechart as a single tool via from blockstate.adapters.langchain import as_tool.
  • Typed Wire Union: Returns BlockstateTurnYield, BlockstateTurnAborted, or BlockstateTurnComplete[T].

Zero-Trust Tool Isolation, PIIVault & Tamper-Evident TurnLedger

Sensitive customer data is stripped at the outermost ingress boundary before Pass 1, encrypted at rest with AES-256-GCM, and detokenised solely inside whitelisted tool handlers requesting Detokenise[T].

Physical Tool GatingAD-3 · BLK-SEC-001
  • No Global Tool Registry: Tools are bound exclusively to @Stage(tools=[...]) definitions.
  • Frozen MappingProxyType: Rebuilt fresh on every turn for the active stage on top of TaskStack.
  • Least-Privilege Injection: Tool functions receive only explicitly declared RunContext[Deps] dependencies.
  • Instant Lockout: Hallucinated or injected tool calls raise SecurityViolationError, log to TurnLedger, and transition to lockout.
PIIVault & Detokenise[T]AD-7 · AES-256-GCM
  • Ingress Tokenisation: Replaces NINo, NHS numbers, SSNs, postcodes, cards, emails, and phones with HMAC tokens (<VAULT:POSTCODE_01>).
  • Encrypted Vault Map: Cleartext mappings live only in SessionCheckpoint.vault_map encrypted via AES-256-GCM with AAD binding and key-rotation support.
  • Zero Exception Leakage: Pydantic ValidationError reprs are scrubbed so raw invalid PII never appears in logs or traces.
SHA-256 TurnLedger & WALAD-8 · EU AI Act Art. 12
  • Synchronous Chain Commit: Computes SHA256(RFC8785_JCS(prev_hash, prompt_hash, vaulted_input_hash, vaulted_output_hash, exposed_tools, ...)) before releasing session lease.
  • Session-Partitioned Buffer: Preserves monotonic causal turn ordering across distributed workers.
  • 10s SIGTERM WAL Drain: Spills un-flushed records to .blockstate/wal/ledger.wal on shutdown or sink backpressure.
